# QA Checklist

## Must-pass items

- It's 16:9 landscape.
- The background is a clean white.
- Xiaohei is present.
- Xiaohei carries the core action, not just decoration.
- It doesn't replicate an old example composition; it invents a fresh metaphor for the current article.
- The scene is quirky, creative, and fun.
- Clean and airy; the subject takes up no more than about 60% of the canvas.
- One image explains only one core structure.
- Annotation labels are few, short, and readable.
- Orange is used only for the main path or arrows.
- Red is used only for emphasis, problems, warnings, or results.
- Blue is used only for supplementary notes, feedback, or system state.

## Failure signals

Regenerate or make local edits when any of these appear:

- A title like "Common Pitfalls / Workflow / System Architecture / Roadmap" in the top-left corner.
- Xiaohei looks like a mascot, an emoji sticker, or a cutesy cartoon character.
- The image looks like a PPT, course slide, or formal flowchart.
- Too many elements, too many arrows, too many nodes.
- Text turns into long explanatory paragraphs.
- Background has paper texture, shadows, gradients, beige, or noise.
- Realistic UI screenshots or tech-style interfaces.
- Severe typos or unreadable labels in the text.
- The scene is too rigid, with no absurd metaphor.
- Too similar to the compositions in `assets/examples/`.

## Iteration methods

- Too generic: make Xiaohei the action subject and add one strange-but-plausible metaphor.
- Too complex: cut nodes; keep only one action and 3-5 short labels.
- Too cute: emphasize deadpan, blank serious expression, not cute, not mascot.
- Too PPT-like: remove titles, borders, tidy grids, and excess arrows; turn it into a hand-drawn scene.
- Too close to an old case: keep the core meaning, but swap out the main object and Xiaohei's action.
- Text errors: prefer local editing; if there are many, regenerate with fewer labels.

## Delivery judgment

A high-quality image should make readers feel "that's a bit weird" first, then understand the structure within 1 second.

If it looks like a tutorial page at first glance rather than a quirky product sketch on a blank sheet, it fails.
