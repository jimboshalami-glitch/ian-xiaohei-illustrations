# Composition Patterns & Originality Rules

## Base structure types

Pick one structure per image; don't mix too many.

### Workflow

Fits: input -> processing -> output, content production, AI workflows, automation chains.

How to draw: inputs on the left, Xiaohei or a weird machine processing in the middle, output on the right, orange arrows for the main flow.

### System subsystem

Fits: information sources, filters, databases, renderers, agent system components.

How to draw: only 3-5 core modules; Xiaohei takes part in one key action.

### Before/after contrast

Fits: chaos/order, manual/automatic, scattered/collected, anxious/stable.

How to draw: chaos on the left, stability on the right, an orange arrow in between. Characters can be more exaggerated.

### Character states

Fits: user pain points, creator states, tool overload, information anxiety, stuck-to-running.

How to draw: 2-4 small states, each with one short label.

### Conceptual metaphor

Fits: content factory, information warehouse, mental black box, workflow machine, automated daily report.

How to draw: one big weird object or machine, few inputs, one output. It needs a memorable hook.

### Method layering

Fits: methodology frameworks, system levels, capability stacks, layered content systems.

How to draw: boxes stacked layer by layer — not a formal pyramid; Xiaohei moves bricks or assembles it from the side.

### Map route

Fits: idea to launch, user journey, content handoff path, learning path.

How to draw: one winding path, a few nodes, Xiaohei leading a line or walking it.

### Mini-comic panels

Fits: failure to success, real processes, snarky commentary, before/after usage changes.

How to draw: 2-4 small scenes, each panel expressing exactly one action.

## Original metaphor generation

Always reinvent the metaphor from the current article; never copy old images.

### Three steps

1. Translate the abstract concept into a physical action: getting stuck, leaking, getting heavy, sorting, settling, fermenting, opening a door, folding, unpacking, looping back.
2. Translate the system structure into a low-tech object: a broken machine, a cardboard box, a drawer, a water pipe, a mailbox, a weird gauge, a scale, a well, a ladder, a strange workstation.
3. Make Xiaohei perform the action: not standing beside it, but wedged inside the machine, pulling the wrong cable, guarding the gate, hauling, patching, weighing, holding the ladder steady, taking notes, stuffing things into some bizarre device.

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, water pipe, ball of yarn, sluice gate, turntable, black box, hole punch, pasta press, clothesline, weird workstation.
- Use only 1-2 per image; don't pile them up.

### Xiaohei action pool

- Pull, haul, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, unwrap, mark, recycle.
- Actions must serve the core meaning — weird for its own sake is a no.

## Anti-copy rules

Don't open or replicate `assets/examples/` by default. These images are only for style calibration: line density, whitespace, color restraint, Xiaohei's vibe.

Unless the user explicitly says "copy this one / recreate this composition / remix this case", never directly reuse these old compositions:

- Conveyor belt with two breakpoints
- Xiaohei pulling the judgment lever inside the content machine
- Xiaohei becoming a funnel sorting traffic/trust/conversion
- Xiaohei cutting the material fish
- Xiaohei leading the handoff path
- Xiaohei pulling three layers of information sources
- Three Xiaoheis each holding a megaphone / building a bridge / opening a door
- Xiaohei stamping scripts at the toolbox
- Xiaohei holding a sign while looking at the common-pitfall path

Even for similar themes, use a new metaphor. For example, a "handoff path" doesn't have to be drawn as a route — it could be Xiaohei attaching the tail of a piece of content to a doorknob; "one fish, many uses" doesn't need a fish — it could be Xiaohei pressing one paper ball into several shapes.
