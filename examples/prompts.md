# Prompt Examples

The prompts below can be copied directly into Codex.

## Illustration planning only

```text
Use $ian-xiaohei-illustrations — don't generate images yet.
Analyze where the article below deserves illustrations and output a shot list of about 5 images.
For each image, specify:
- which paragraph it follows
- the topic of the image
- the core meaning
- the structure type
- what Xiaohei is doing in the image
- suggested elements
- suggested annotation labels

<paste article>
```

## Article inline illustrations

```text
Use $ian-xiaohei-illustrations to generate 4 Xiaohei quirky inline illustrations for the article below.
Requirements: 16:9 landscape, pure white background, black hand-drawn line art, a few red/orange/blue handwritten annotations.
Each image explains only one core structure — no PPT infographics, no cutesy cartoons.

<paste article>
```

## Long-article illustration strategy

```text
Use $ian-xiaohei-illustrations to build an illustration strategy for this long article.
Don't illustrate evenly — only pick cognitive anchors: core judgments, input/output loops, before/after contrasts, common pitfalls, handoff paths.
Default to 6-8 images; output the shot list first without generating images.

<paste article>
```

## One image for a single idea

```text
Use $ian-xiaohei-illustrations to create one 16:9 inline illustration for this idea:

Trust isn't shouted into existence — it's paved, one piece of evidence at a time.

The scene should be weird but clean, and Xiaohei must carry the core action.
At most 5 short handwritten annotation labels.
```

## Workflow theme

```text
Use $ian-xiaohei-illustrations to create one image for: "turning one raw piece of material into three kinds of content: traffic, trust, and conversion."
Don't draw a formal flowchart, and don't reuse the old "one fish, many uses" composition.
Invent a fresh low-tech metaphor and make Xiaohei perform the core action.
```

## Editing: remove a title

```text
Use $ian-xiaohei-illustrations to edit this image for me.
Remove the "Workflow" title and its underline in the top-left corner; keep everything else unchanged.
Do not add any new text or objects.
```

## Editing: strengthen Xiaohei's involvement

```text
Use $ian-xiaohei-illustrations — this image has the right direction, but Xiaohei feels more like decoration.
Keep the core meaning unchanged and regenerate: make Xiaohei the one actually driving the structure.
Make the scene a bit weirder, but still pure white, clean, and minimal on text.
```

## Generate a style sample set

```text
Use $ian-xiaohei-illustrations to produce 5 Xiaohei inline illustrations on different themes.
Themes: information overload, product validation, content compounding, one-person company, building trust.
Generate each one separately — don't combine them into a single image.
```
